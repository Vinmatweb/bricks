# Bricks

Samostatné varianty informačního webu LEGO Castle:

| Složka | Varianta | Adresa |
| --- | --- | --- |
| `castle-GPT/` | Castle Atlas, GPT | https://vinmat.eu/bricks-gpt/cs/castle/ |
| `castle-Claude/` | Připraveno pro Claude | Zatím bez webu |
| `castle-Gem/` | Připraveno pro Gemini | Zatím bez webu |

Všechny zdroje, katalogy, obrazové archivy a sestavovací skripty GPT verze jsou v `castle-GPT/`. V kořeni zůstává pouze tento rozcestník a společné nastavení GitHubu.

Podrobnosti sestavení a publikace: [castle-GPT/README.md](castle-GPT/README.md).
