# Castle Atlas — archiv GPT v1

Zachovaná původní verze před přepracováním podle porovnání Claude / Gemini / GPT, ze dne 30. 10. 2026.

Adresa: https://vinmat.eu/bricks-gpt-v1/cs/castle/

Zdrojové HTML, CSS, JavaScript, katalog a obrazové archivy odpovídají v1. U sestavení je změněna pouze cílová cesta.

Sestavení: `python bricks-gpt-v1/scripts/build.py`
Kontrola: `python bricks-gpt-v1/scripts/verify.py`

Publikovaný export je v hlavním repozitáři domény, složce `bricks-gpt-v1/`. Fotografie zůstávají na sdílené adrese `/bricks/cs/castle/assets/catalog/`. Archivní verze se při úpravách v2 nepřepisuje.
