# Castle — Gemini

Produkce: https://vinmat.eu/bricks-gem/cs/castle/

Import uživatelem dodaného `lego_castle_codex (3).html`. Kompletní aplikace, styly a data jsou v `index.html`; doplněna je pouze kanonická URL a popis stránky. Pro vzhled se načítá Tailwind CDN a Google Fonts, obrázky podle původního HTML.

Publikovaná kopie je v repozitáři `Vinmatweb/vinmatweb.github.io` na cestě `bricks-gem/cs/castle/index.html`, protože projektové Pages repozitáře `bricks` obsluhuje cestu `/bricks/`. Při další úpravě zde je třeba aktualizovat i tuto publikovanou kopii. Užití zdrojové verze nepotřebuje build ani API klíče.
